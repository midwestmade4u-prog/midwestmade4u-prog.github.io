What it does

  • Twelve months across, thirty-one days each — a full year without turning a page.
  • Undated. Start in August, start in January, start whenever you actually started.
  • Running days and hours columns, because states count different things.
  • A days required box at the top so your own state's target stays in front of you.
  • Mark days however you like — a tick, H for a half day, F for a field trip.

A note on requirements

Attendance rules differ from state to state. Some count days, some count instructional hours, and some ask for neither. This sheet is built to record either one, but it is a record-keeping tool and not legal guidance — check your own state's requirement before you rely on it.
